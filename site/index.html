How it works

Generate a focused local canvas

  1. Choose a functionPass one file and symbol to the CLI.
  2. Use your language serverThe CLI asks the server already installed on your machine.
  3. Open the HTML fileSearch the path, inspect source, and share the file when appropriate.

Use the bundled sample first. It writes a complete canvas in a temporary folder.

Privacy and limits

Keep code local and check uncertain calls

  • Local analysisThe CLI starts the language server on your machine.
  • Bounded outputFree maps include callers and callees through two hops.
  • Read-only inputThe CLI reads source files without changing them.

Read the canvas beside the code before making an important decision.

Install and run

Install the CLI and map a function

Install Rust and the language server for the code you want to inspect before running the command.

1 · Install from the repository
cargo install --git https://github.com/B-Divyesh/sf-function-flow-canvas
2 · Map one symbol
ffc src/api.rs --symbol handle_request --depth 2
