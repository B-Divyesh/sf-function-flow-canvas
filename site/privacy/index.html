Legal / privacy

Source stays on your machine.

Effective August 28, 2026 · version 1.0

What the CLI processes

The CLI reads the source file you select and talks to the language server that it launches on your machine. It writes the canvas to the path you choose. Source, symbols, snippets, and generated canvases are never sent to Function Flow Canvas or Sociobot.

What this site stores

The site uses no advertising, behavioral analytics, cookies, or third-party scripts. Its service worker may cache public site files on your device so the docs and demo remain available offline.

If you buy Pathfinder, the returned license token and its latest verification result are stored in your browser’s localStorage under sb_license:function-flow-canvas. The CLI stores the token and daily verdict in your operating system’s user configuration directory only after you provide a license.

License verification and payment

License verification sends only the token to the Sociobot billing API, at most once per day per client. Source code and canvas content are not included. Checkout is hosted by Sociobot and Dodo, the merchant of record; their privacy terms apply to payment information.

Your control

You can clear site data in your browser and remove the CLI license cache at any time. Uninstalling the CLI does not delete canvases you created. Generated HTML files remain entirely under your control.

Contact

Questions can be filed in the public issue tracker. Do not include private source or license tokens.
