How Function Flow Canvas handles data

Effective September 5, 2026 · version 0.1.0

Source code

The CLI reads the source file you choose. It talks to the language server it starts on your machine. It writes the canvas to the output path you choose.

The generated canvas has its data, styles, and behavior in one HTML file. The CLI reads source files without changing them.

Site data

This site has no account sign-in, cookies, advertising, or behavioral tracking. It uses no third-party scripts.

A service worker can cache public site files after a visit. This lets the sample and documentation reopen when your browser is offline.

Sample data

The demo stores its active mode, filter, and direction in the demo:function-flow-canvas: browser storage namespace. Reset demo removes saved sample controls. Start for real removes all demo state. The demo does not read or write other site data.

Your control

You can clear site data in your browser. You can delete generated HTML files whenever you no longer need them.

Contact

Questions can be filed in the public issue tracker on GitHub. Do not include private source.
