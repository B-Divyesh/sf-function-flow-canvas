Accuracy and boundaries

Canvases reflect results returned by your chosen language server. Dynamic dispatch, generated wiring, reflection, macros, or unsupported language features may be incomplete. Treat the output as a navigation aid, not as proof of runtime behavior, security, or correctness.

Free edition

The free edition includes inbound and outbound analysis through depth 2, source snippets, type context, HTML output, filtering, and JSON output. Accessibility, privacy, and export are never paywalled.
